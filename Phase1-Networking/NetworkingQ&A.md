## 1. Computer Network Basics

1. What is a computer network?  
a) A single computer system  
b) Interconnected computing devices for resource sharing  
c) A type of software  
d) An internet browser  
Explanation: A network connects multiple devices to share data and resources.  
Answer: B

2. What is the primary purpose of a network?  
a) To play games  
b) To share resources and information  
c) To increase computer speed  
d) To block viruses  
Explanation: Networks enable sharing of files, printers, and internet access.  
Answer: B

3. What is bandwidth?  
a) The width of a network cable  
b) The maximum data transfer rate of a network  
c) The number of computers on a network  
d) The strength of a wireless signal  
Explanation: Bandwidth measures how much data can travel through a network in a given time.  
Answer: B

4. What is latency?  
a) Data transfer speed  
b) Time delay in data transmission  
c) Network cable length  
d) Number of network users  
Explanation: Latency is the time it takes for data to travel from source to destination.  
Answer: B

5. What is a node in a network?  
a) A network cable  
b) Any device connected to a network  
c) A software program  
d) A type of virus  
Explanation: Nodes include computers, printers, servers, and other network devices.  
Answer: B

6. What is a protocol?  
a) A network cable  
b) Rules governing data communication  
c) A type of computer virus  
d) Network hardware  
Explanation: Protocols define how devices communicate over a network.  
Answer: B

7. What is data packet?

c) A type of computer

Answer: B

8. What is a router?

c) A type of cable  
d) Internet browser

Answer: A

9. What is a switch?  
a) Device that connects different networks  
b) Device that connects devices within a network

Explanation: Switches connect multiple devices on the same network.

10. What is a hub?  
a) A basic network device that broadcasts data to all ports

## 7. Calculations Based (Numerical Problems)

> *Note: These worked numerical problems repeat frequently throughout the source material (in "Calculations Based" and "Easy Calculation Based" sections). Each unique problem type is listed once below with its solution method.*

1. Data Transmission Time

Q: A 1 MB file is transmitted over a 10 Mbps link. What is the transmission time?  
- File size = 1 MB = 8 Mb; Link speed = 10 Mbps  
- **Transmission time = Size / Bandwidth = 8 / 10 = 0.8 s → Answer: A (0.8 s)**

2. Propagation Delay

Q: A signal travels through a 2000 km fiber optic cable at 2 × 10^8 m/s. What is the propagation delay?  
- Distance = 2000 km = 2 × 10^6 m  
- **Delay = Distance / Speed = 2×10^6 / 2×10^8 = 0.01 s = 10 ms → Answer: A**

3. Bandwidth-Delay Product

Q: A 1 Gbps link has a round-trip delay of 50 ms. What is the bandwidth-delay product?  
- **BDP = Bandwidth × RTT = 1 Gbps × 50 ms = 50×10^6 bits = 50 Mb → Answer: A**

4. Maximum IP Addresses / Hosts in a Subnet

Q: How many hosts can be assigned in a subnet with mask 255.255.255.240 (/28)?  
- Host bits = 32 − 28 = 4  
- **Hosts = 2^4 − 2 = 14 → Answer: A**

5. Effective Throughput

Q: A 100 Mbps link has 20% overhead. What is the effective throughput?  
- **Effective throughput = 100 × (1 − 0.2) = 80 Mbps → Answer: A**

6. Channel Capacity (Shannon)

Q: A channel has bandwidth 3 kHz and SNR = 15. Find channel capacity.  
- Capacity C = B log₂(1 + SNR); log₂(16) = 4  
- **C = 3000 × 4 = 12 kbps → Answer: B**

7. Delay × Bandwidth Product

Q: 10 Mbps link with 100 ms delay. Bandwidth-delay product?  
- **Product = 10×10^6 × 0.1 = 1×10^6 bits = 1 Mb → Answer: A**

8. Utilization in Stop-and-Wait

Q: A 1 Mbps link with 100 ms one-way delay uses Stop-and-Wait. Frame size = 10 kb. Utilization?  
- Transmission time = 10 kb / 1 Mbps = 10 ms; Round-trip = 200 ms  
- **U = 10 / (10 + 200) ≈ 0.05 → Answer: D**

9. Subnetting — Number of Subnets

Q: Number of subnets created if /24 network uses /26 mask?  
- **Subnets = 2^(26−24) = 2^2 = 4 → Answer: A**

10. Number of Hosts

Q: /22 subnet mask → number of hosts per subnet?  
- Host bits = 32 − 22 = 10  
- **Hosts = 2^10 − 2 = 1022 → Answer: A**

11. Transmission Delay

Q: 5 MB file over 50 Mbps link. Transmission delay?  
- 5 MB = 40 Mb  
- **Delay = 40 / 50 = 0.8 s → Answer: A**

12. Efficiency in Sliding Window

Q: Window size = 5, link delay = 20 ms, frame size = 1 kb, bandwidth = 10 kb/ms. Efficiency?  
- U = W / (1 + 2a), where a = Propagation / Transmission  
- **Approximation → U ≈ 0.8 → Answer: B**

13. IPv4 Address Range

Q: Network 192.168.5.0/26. Last usable IP?  
- /26 → 64 addresses per subnet; Usable IPs = 192.168.5.1 – 192.168.5.62  
- **Answer: A (192.168.5.62)**

14. CRC Calculation

Q: Frame = 1101011011, Generator = 1011. Number of CRC bits?  
- **CRC bits = degree of generator = 4 − 1 = 3 → Answer: A**

15. Propagation Speed

Q: Signal takes 0.2 ms over 40 km cable. Speed?  
- **Speed = distance / time = 40,000 / 0.0002 = 2×10^8 m/s → Answer: A**

16. Channel Bandwidth

Q: Max data rate for noiseless 3 kHz channel with 8 signal levels?  
- **C = 2 × B × log₂(M) = 2 × 3 × 3 = 18 kbps → Answer: D**

17. Queuing Delay

Q: Average queue length = 10 packets, service rate = 1000 packets/s. Delay?  
- **Delay = Queue length / Service rate = 10 / 1000 = 0.01 s → Answer: A**

18. Maximum TCP Window

Q: 100 Mbps link, RTT = 50 ms. Maximum TCP window size?  
- **Window = Bandwidth × RTT = 100×10^6 × 0.05 = 5 Mb → Answer: B**

19. Number of Subnets

Q: /16 network divided into /18 subnets → Number of subnets?  
- **Subnets = 2^(18−16) = 2^2 = 4 → Answer: A**

20. Transmission Time with Overhead

Q: 1000-byte packet over 1 Mbps link. 20% header overhead. Transmission time?  
- Packet size = 1000 × 1.2 × 8 bits = 9600 bits  
- **Transmission time = 9600 / 10^6 = 9.6 ms → Answer: C**

- **/26 subnet last usable IP**: e.g., 192.168.1.0/26 → usable range 1–62 → last usable = **192.168.1.62**
